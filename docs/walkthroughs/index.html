Transmission — Process Walkthroughs

Task-oriented guides to the real lifecycle of a content audit. Each is mental-model-first, with numbered steps using exact UI labels, and ends with a self-check. Read them in order the first time; revisit individually after.

Every label, menu path, and shortcut here is verified against the 2.4.1 source — not memory.

Reading path (the audit lifecycle)

A. Set up & orient

  1. Getting Started — install, open a file, what gets added, save & round-trip
  2. Project Setup — Project Settings vs App Settings; what travels with the file

B. The core audit 3. Running the Audit Pass — the field-bar clusters, KKE keys (1–5), the embedded browser 4. Finding the Work — search scopes, filters, saved filters, Global Search 5. Bulk Operations — multi-select + the Multi-bar, batch assess 6. Tagging, Grouping & the Glossary — Group vs Primary vs Tags; the glossary

C. Classify for migration 7. Content Types & the Crosswalk — Content Type → Renders as → Target; the registry 8. Suggested_KKE — rubrics, AI, GA; how the sources combine 9. Consolidate — the picker, candidates, dead-target warnings 10. Non-200 Triage — clearing redirects/404s/errors in one sweep

D. Collaborate & review 11. SME Review — export → fill → import → resolve 12. Multi-auditor Merge — combining parallel audits

E. Architect the future site 13. Sitemap & IA — build the sitemap, place pages, references, phases 14. Build & Direction — Target Specs, build metadata, Builder/Writer/Migrator

F. Ship it 15. Redirects — the editor, resolution priority, the 404 sentinel, chain check 16. Producing the Outputs — the report catalog: what each is for 17. Migration Tracker Hand-off — the multi-sheet engineering workbook 18. Pre-flight & Hand-off — the Pre-Handoff Check + change log

G. Power features 19. Templates — audit templates + report templates 20. Component Inventory — tagging components, the library, the report
