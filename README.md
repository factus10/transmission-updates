# transmission-updates (moved)

Transmission's docs, changelog and downloads now live in the main repository:

- Site: https://factus10.github.io/transmission/
- Downloads: https://github.com/factus10/transmission/releases/latest
- Source: https://github.com/factus10/transmission

Every page here redirects there. This repo stays up only because copies of the
app at 2.26.0 and earlier check `update-manifest.json` here for updates. Its
links already point at the main repository; at the 2.27.0 release its
`version`, `publishedAt` and `notes` get one last update so those copies are
offered the new version. The releases here are kept so old download links keep
working; new releases are not mirrored.
